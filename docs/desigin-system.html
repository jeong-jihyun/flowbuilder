01

Professional

Intelligent

03

Research

검증 가능한 근거와 연구 기반의 전문성 강조

04

Enterprise

공공기관과 기업 고객에게 적합한 안정적인 인터페이스

Practical

기술 소개를 넘어 실제 업무에 활용되는 제품 중심 UI

08 / Developer Tokens

CSS 디자인 토큰

서비스와 컴포넌트가 공유하는 단일 토큰 기준입니다.

:root {

  --color-blue-600: #2864FF;
  --color-cyan-500: #00BCD4;
  --color-blue-400: #4B8EFF;

  --color-bg: #FFFFFF;
  --color-bg-subtle: #F4F7FB;
  --color-text-primary: #0B2045;
  --color-text-secondary: #64748B;
  --color-border: #E3EAF3;

  /* Semantic */
  --color-success: #16A36A;
  --color-warning: #E9A23B;
  --color-danger: #DC4545;
  --color-info: #2864FF;

  /* Spacing */
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;
  --space-12: 48px;
  --space-16: 64px;

  /* Shape & Layout */
  --radius-sm: 6px;
  --radius-md: 10px;
  --radius-lg: 16px;
  --radius-xl: 20px;
  --container-width: 1200px;

  /* Typography */
  --font-family: "Pretendard", "Inter",
    "Noto Sans KR", sans-serif;
}

위 토큰은 이 문서의 제안 사양입니다. 실제 배포 전 기존 웹사이트의 CSS, 로고 원본, 브랜드 가이드와 대조해 확정해야 합니다.

10 / Governance

운영 및 변경관리 원칙

디자인 시스템이 프로젝트마다 분기되지 않도록 변경 승인과 버전 정책을 정의합니다.

항목 운영 규칙
Single Source 모든 서비스는 중앙 디자인 토큰과 공통 컴포넌트를 사용
Reuse 동일 기능의 UI를 페이지별로 중복 구현하지 않음
Change Log 토큰·컴포넌트 변경 시 사유, 영향 범위, 변경일, 담당자 기록
Versioning 디자인 시스템 버전과 개별 서비스 버전을 분리 관리
Accessibility 키보드 조작, 명도 대비, 포커스, 스크린 리더 고려
Regression 공통 컴포넌트 변경 시 주요 화면 회귀 테스트
