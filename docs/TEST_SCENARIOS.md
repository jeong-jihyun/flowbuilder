## 12. 종단 시나리오 (한 번에 쭉)

1. 계정 A: 그룹 만들기 → B를 Editor로 추가 → Credentials에 GAS 비밀값 등록
2. Workflow 만들기: Webhook → GAS → If/Else(결과 확인) → 성공/실패 Transform → 저장 → 자동 실행 켜기
3. 터미널/REST 도구로 Webhook 주소에 POST → Executions에서 성공 확인 → 일부러 GAS 비밀값을 지워 다시 POST → 실패 확인 → "다시 실행"
4. 계정 B: 같은 Workflow 열기(편집 가능), Credentials는 목록만 가능한지 확인

통과 기준: 3번에서 성공·실패 두 기록이 Executions에 남고, 실패한 노드 오류 문구가 원인을 알려 준다.
